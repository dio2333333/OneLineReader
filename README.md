# 一行 · Reader

一行 · Reader 是一个 Windows 单行阅读器。它把小说显示在可拖动的悬浮阅读条中，支持鼠标、滚轮、全局快捷键和老板键。可以离线导入 TXT、EPUB，也可以连接自建的 Reader 服务，在桌面和网页之间继续阅读。

本程序配套使用 **[hectorqin/reader](https://github.com/hectorqin/reader)**，是独立的 Windows 客户端。在线功能对接该项目的 [`/api/v1` 接口](https://github.com/hectorqin/reader/blob/main/docs/api.md)。旧版 `/reader3` 接口需要先升级服务端。

## 下载与运行

- 系统要求为 Windows 10 或 11，安装 .NET Framework 4.8 或更高的 4.x 版本。
- 从本仓库的 Releases 下载维护者上传的便携 ZIP，解压到有写权限的文件夹，双击 `OneLineReader.exe`。也可以按本文末尾的步骤自行构建。
- 首次启动可以点击“试读示例”。读自己的书时，在“书架”中点击“导入”，选择 TXT 或 EPUB，然后打开书籍。
- TXT 支持 UTF-8、带 BOM 的 UTF-16 和 GB18030。EPUB 提取可阅读文字和章节目录。图片、PDF 和漫画没有单行正文模式。

## 阅读操作

| 操作 | 默认方式 |
| --- | --- |
| 下一行 | 点击阅读条，或把鼠标放在阅读条上向下滚动 |
| 上一行 | 在阅读条上向上滚动 |
| 阅读条获焦时翻行 | 方向键、Page Up / Page Down，或按空格前进 |
| 全局下一行 / 上一行 | Alt+C / Alt+Z |
| 隐藏或恢复阅读条 | Alt+V。阅读条获焦时也可以按 Esc 隐藏 |
| 打开控制台 | Alt+S，或从系统托盘打开 |
| 移动或调整宽度 | 左键拖动阅读条，或拖动其右下角调整宽度 |
| 章节目录、自动翻页、立即同步 | 在阅读条上点击右键 |

在“阅读外观”可调整字体、字号、文字与背景颜色、阅读条尺寸、整体不透明度、背景不透明度和置顶。阅读条按可用宽度排成一行。背景不透明度最低为 **1%**，“低调灰”预设也使用 1%，给文字之间的空白保留鼠标接收区域。原来保存的 0% 设置会按 1% 加载。

在“快捷操作”可重新录入并保存快捷键，支持 F1、F2 等独立功能键和 Ctrl、Alt、Shift 组合键。F12 为 Windows 保留键。若某个组合已被其他应用占用，该页会显示注册结果和实际使用的按键。关闭控制台会收起到托盘，彻底退出请使用托盘菜单。

## 连接自建 Reader

1. 按 [hectorqin/reader 的项目说明](https://github.com/hectorqin/reader) 部署服务，确保能用自己的账号登录其网页。
2. 在一行 · Reader 打开“Reader 同步”，填写自己的 Reader 站点地址，例如 `https://reader.example.com/`。反向代理部署在子路径时保留子路径，例如 `https://example.com/reader/`。也可以粘贴以 `/api/v1` 结尾的地址。
3. 点击“测试连接”，确认服务返回 API v1。输入该 Reader 站点的用户名和密码，点击“登录并同步书架”。
4. 在书架选择“Reader 书架”查看个人书架，或选择“Reader 在线书库”浏览服务端藏书。支持分页和搜索。打开在线书库中尚未加入个人书架的书时，客户端会先尝试将它加入书架。

建议为 Reader 配置 HTTPS，并使用 Windows 信任的证书链。服务地址的协议、域名、端口和代理子路径应与网页访问地址一致。

## 同步与离线阅读

- 打开或恢复在线书籍时读取云端进度。停止翻页约 30 秒后，有新进度才自动上传。
- 应用运行且 Reader 已登录时，每 5 分钟固定联系服务。打开在线书籍时检查云端进度并提交待同步位置。没有打开在线书籍时检查会话。中途上传不会重置这个周期。
- 隐藏阅读条、收起控制台、切换书籍或退出时保存本机位置，有待上传进度时尝试同步。也可以随时使用“立即同步”。
- 两端都有更新时会提示冲突，由你选择保留本机位置或采用云端位置。本机记录按字符定位，跨设备按章节及章内比例恢复，页面布局不同可能产生小幅偏差。
- 已加载并缓存的在线章节可离线阅读，未缓存的章节需要网络。上传失败时进度先保留在本机，之后自动重试。

## 本地数据

默认数据目录是 EXE 同目录的 `data\`。它保存设置、阅读进度、书籍和缓存。应用密码不会保存到磁盘。登录后的访问令牌和刷新令牌由当前 Windows 用户的 DPAPI 加密，跨电脑或 Windows 用户迁移后需要重新登录。

升级时先从托盘退出应用，将新版 EXE 放入原程序目录，保留 `data\`。也可用 PowerShell 的以下方式指定数据目录。

```powershell
.\OneLineReader.exe --data-dir 'D:\MyReaderData'
```

如果要从空白状态启动，可以解压到新目录，或为 `--data-dir` 指定一个新的空文件夹。不要把自己的数据目录、配置备份或缓存放进 GitHub 仓库或发布 ZIP。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 测试连接失败或返回 HTTP 400 | 对照浏览器中可访问的 Reader 地址，检查协议、端口和子路径。服务端切换到 HTTPS 后请填写 HTTPS 地址 |
| 测试连接成功但登录失败 | 使用该 Reader 实例的账号，检查提示区的登录错误及请求地址 |
| 阅读条不见了 | 试用老板键或从托盘打开控制台，再到“阅读外观”选择“移回屏幕内” |
| 点击落到背后的窗口 | 检查“始终置顶”，并确认阅读条覆盖鼠标所在位置。本版背景不透明度最低为 1% |
| 滚轮在阅读条未获焦时无效 | 检查 Windows 鼠标设置中的“悬停时滚动非活动窗口”，也可点击阅读条后再滚动 |
| 全局快捷键无效 | 在“快捷操作”查看冲突提示，改用空闲组合，或退出占用相同按键的旧版进程 |

## 从源码构建

在 64 位 Windows 上安装 .NET Framework 4.8，在仓库根目录打开 PowerShell。构建脚本调用系统的 .NET Framework C# 编译器和 WPF 程序集。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

产物为 `dist\OneLineReader.exe`。如需运行本地测试，在命令末尾加 `-Test`。测试使用合成书籍和替身 HTTP 服务。制作 GitHub Release 时，可将构建出的 EXE 和 README 一起打包上传。

| 路径 | 内容 |
| --- | --- |
| `src/` | WPF 界面、阅读条、阅读进度、Reader API 客户端和本地存储 |
| `tests/` | 阅读、存储和 Reader API 的本地测试 |
| `build.ps1` | 编译与测试入口 |
| `app.manifest` | Windows 应用清单 |

本版为 **v1.0.4**，首次整理 GitHub 发布目录，并将背景不透明度下限设为 1%。本地与在线阅读使用的进度定位格式见 [Reader locator.ts](https://github.com/hectorqin/reader/blob/main/web/src/ui/locator.ts)。
